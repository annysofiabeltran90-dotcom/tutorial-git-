# TUTORIAL DE GIT Y GITHUB

## Descripción del proyecto

Este repositorio contiene un tutorial de Git y GitHub elaborado con base en el libro oficial Pro Git, con el propósito de comprender y aplicar los comandos básicos del sistema de control de versiones.

## Objetivo

Documentar el proceso de aprendizaje y utilización de Git mediante la elaboración de documentos que explican los principales conceptos y comandos de esta herramienta.

## Organización del repositorio

El repositorio está organizado en dos carpetas principales:

- **Word:** contiene los documentos editables de cada capítulo del tutorial.
- **PDF:** contiene los documentos de cada capítulo exportados en formato PDF.

## Proceso realizado

Para desarrollar esta actividad se llevaron a cabo los siguientes pasos:

1. Creación de una cuenta en GitHub.
2. Instalación de Git en el computador.
3. Creación de un repositorio en GitHub.
4. Clonación del repositorio mediante el comando `git clone`.
5. Elaboración de los documentos del tutorial en Microsoft Word, tomando como referencia el libro Pro Git.
6. Exportación de los documentos a formato PDF.
7. Organización de los archivos en las carpetas Word y PDF.
8. Utilización del comando `git add` para agregar los archivos.
9. Utilización del comando `git commit` para registrar los cambios.
10. Utilización del comando `git push` para enviar los archivos al repositorio remoto.

## Comandos principales utilizados

- `git clone`: permite clonar un repositorio remoto.
- `git add`: prepara los archivos para confirmar los cambios.
- `git commit`: registra los cambios en el historial del repositorio.
- `git push`: envía los cambios al repositorio remoto de GitHub.
- `git status`: permite consultar el estado de los archivos.
- `dir`: permite visualizar los archivos y carpetas desde Git Bash en Windows.
